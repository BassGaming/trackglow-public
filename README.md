# TrackGlow

TrackGlow lights up your room with live race control: flags, safety cars and race events from live timing, played on your RGB gear through OpenRGB. For Windows.

## Download

1. Download the latest `TrackGlow-<version>.zip` from [Releases](https://github.com/BassGaming/trackglow-public/releases/latest).
2. Extract it to a folder you can write to, for example `Documents\TrackGlow` (not Program Files).
3. Start `TrackGlow.exe`. You need the OpenRGB SDK server running (port 6742).

TrackGlow updates itself: when a new version is out, a green arrow appears in the top left. One click installs it.
